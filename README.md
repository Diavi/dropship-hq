# Dropship HQ

A single-file dropshipping command center for researching products, analyzing margins, choosing global marketplaces, and generating listing packages.

## Live Demo

[https://diavi.github.io/dropship-hq/dropship-dashboard.html](https://diavi.github.io/dropship-hq/dropship-dashboard.html)

## What it includes

- Market setup for country, currency, and selling platforms
- Agent command center for product test ideas
- Product analyzer with scoring and verdicts
- Listing builder for marketplace copy and launch plans
- Profit calculator
- Platform rules and launch checklists

## Open locally

Open `dropship-dashboard.html` in a browser — no installation needed.

## Platforms supported

- Lazada
- TikTok Shop
- Shopee
- And more
